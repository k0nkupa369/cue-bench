# Play and measure a partial delivery

A visitor receives 12 ink and 8 moss jackets, sees a timeout, checks the journal and compares the outcome with a recorded model run. New screenshot runs record where a click landed. A paired experiment measures whether observing again after navigation reduces premature closure.

## Delivery order

1. **Playable case** is independent. Build a key-free static case suitable for GitHub Pages, with a stable replay link backed by the published partial-receipt recording. Keep visitor choices in the browser. Demonstrate a correct recovery and a duplicate receipt in desktop and mobile Chromium. Verify relative URLs under the repository subpath. Review the interaction before production deployment.
2. **Observed clicks and refresh policy** is independent of the public case. Add optional evidence to new standalone screenshot recordings. Record coordinates, observation identity, actual browser click target and whether navigation intervened. Show the marker on its source screenshot. Historical traces keep unknown targets. Preserve the existing batch behavior as the control. The treatment discards the rest of a batch after navigation and requests another observation. Verify both policies in Chromium on the same scripted batch. Check that the published study still verifies.
3. **Matched experiment** depends on the two policies. Start with a runnable, key-free schedule and report. Pair each provider/model, seed, fault and repetition. Hold interface and budgets fixed. Measure premature closure, valid posting, final correctness, excess units, time and request count. Report interruptions and incomplete pairs. Calibrate each provider before a paid collection. Keep new results outside the frozen study.

Use one review branch with independently verifiable changes. Open a PR after end-to-end verification. Deployment and paid collection require a hosting decision and a new spend limit respectively. Unit tests and Jest are excluded by project instruction.

**Execution decision.** Deploy the public GitHub Pages case after passing CI. Use only OpenAI for the new paid experiment, with a US$25 total cap. Claude and Gemini remain available for a separately authorized replication.
